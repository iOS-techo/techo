手引き

はじめての設定（15分・1台で1回だけ）
  1. Safariで console.firebase.google.com を開き、Googleアカウントでログイン
  2. 「プロジェクトを作成」→ 名前は techo など自由 → Googleアナリティクスはオフでよい → 作成
  3. 左メニュー「構築」→「Authentication」→「始める」→「メール／パスワード」を選び有効にして保存
  4. 同じ画面の「Users」タブ →「ユーザーを追加」→ メールアドレスと6文字以上のパスワードを決めて追加（このアプリで使う合言葉です）
  5. 左メニュー「構築」→「Realtime Database」→「データベースを作成」→ 地域は asia-southeast1 → 「ロックモードで開始」
  6. できた画面の上の「ルール」タブを開き、中身を下の枠の内容にすべて置き換えて「公開」
  7. 左上の歯車「プロジェクトの設定」→ 下の「マイアプリ」で </>（ウェブ）を選び、ニックネームを入れて登録 → 表示された apiKey と databaseURL をコピー
  8. この画面の上の4つの欄に貼り付けて「接続する」
  9. もう1台でも同じ4項目を入れて「接続する」。これで自動同期が始まります
{
  "rules": {
    "techo": {
      "$uid": {
        ".read": "$uid === auth.uid",
        ".write": "$uid === auth.uid"
      }
    }
  }
}
ホーム画面のアプリにする
  1. iPad（Safari）：公開URLを開く → 共有ボタン →「ホーム画面に追加」
  2. Android（Chrome）：公開URLを開く → 右上の ⋮ →「ホーム画面に追加」または「アプリをインストール」
  3. どちらも、追加したアイコンから開いて同期の4項目を入力する
写真について
  1. メモの記入画面の 撮影（カメラが起動）と 選ぶ（保存済みから複数選択）から追加できます（1件につき8枚まで）。
  2. 取り込み時に自動で縮小します（原寸 長辺1400px・一覧用 長辺260px）。1枚あたり約0.3MBです。
  3. 電波がなくても追加でき、「送信待ち」と表示されます。つながると自動で送られます。
  4. 一覧のサムネイルをタップすると大きく表示します。指2本でつまむ、ダブルタップ、＋ボタンのいずれでも拡大でき、拡大中は指でずらせます。
  5. 写真は「ファイルに書き出す」の控えには含まれません（Firebase側にのみ保存されます）。
同期のしくみ・お金・色
  1. 書いた瞬間に置き場所へ送り、他アプリから戻った時と15秒ごとに受け取ります。
  2. 電波がない所でも書けます。つながった時にまとめて送られます。
  3. 2台で同時に直しても、1件ごとに新しい方を残すので消えません。
  4. 無料枠（Sparkプラン）で足ります。カード登録は不要です。
  5. ■ 朱＝期日切れ・今日　■ 山吹＝3日以内　■ 藤＝4日以上・期日なし　■ 青磁＝完了

メモを書く

「撮影」はその場でカメラが起動します。「選ぶ」は複数まとめて選べます。自動で縮小して保存します。
